플레이어 사진

images/players 폴더에 이름이나 닉네임으로 사진을 넣으면(예: 깐부.png, steal_h.jpg) 시상식, 결과 화면, 공유 이미지에 얼굴이 나와요. 정사각형 사진이 가장 예뻐요. 이름 뒤에 다른 글자가 붙어도 괜찮아요(예: 깐부 사진.jpg).

점수 배점

무기 이름 고치기

한 줄에 하나씩 '공식 이름 = 보여줄 이름'으로 적어요. 지난 기록에도 바로 반영돼요.

친구 조회 공유

웹 공유 (GitHub Pages) — 관리자 PC가 꺼져 있어도 볼 수 있어요

기록·리플레이·선수 사진은 위의 공유 비밀번호(6자 이상)로 암호화돼서 올라가요. 비밀번호를 모르면 파일을 받아도 읽을 수 없어요. 배그 API 키·디스코드 주소·GitHub 토큰은 올라가지 않아요. 저장소는 공개(Public)로 만들어야 무료 웹사이트가 돼요. 토큰은 GitHub → Settings → Developer settings → Personal access tokens 에서 그 저장소의 Contents 읽기·쓰기(Pages 쓰기도 있으면 좋아요) 권한으로 만들어요.

리플레이 설정

자동 카메라로 볼 때만 적용돼요. 교전 구간은 교전 배속으로 천천히, 교전이 없는 구간은 빨리감기 배속으로 빠르게 지나가요(10배 이상으로 볼 때). 마우스로 지도를 움직이거나 '전체 지도 보기'로 보면 고른 배속 그대로예요. 사진 크기는 1이 원래 크기예요. 저장하면 친구 화면과 웹 공유에도 반영돼요.

리플레이 그림

images/replay 폴더에 그림을 넣으면 리플레이의 보급·투척 무기 아이콘이 그 그림으로 바뀌어요. 파일 이름은 한글이나 영어 모두 돼요: 수류탄(grenade), 화염병(molotov), 연막탄(smoke), 섬광탄(flash), 점착 폭탄(sticky), C4, 블루존 수류탄(bluezone), 보급(carepackage), 열린 보급, 낙하 보급, 신호탄(flare), 판처파우스트(panzerfaust), 박격포(mortar), 연료통(jerrycan).

효과음과 음악

sounds 폴더에 아래 이름으로 파일(mp3, ogg, wav, m4a)을 넣으면 기본 소리 대신 나와요. bgm(시상식 배경음악), reveal(3·4위 공개), tick(슬롯 돌아가는 소리), stop(슬롯 멈춤), fanfare(1등 발표), kill(리플레이 킬).

트로피와 메달 이미지

images 폴더에 trophy, gold, silver, bronze 라는 이름으로 그림 파일(png, jpg, webp)을 넣으면 기본 그림 대신 들어가요.
